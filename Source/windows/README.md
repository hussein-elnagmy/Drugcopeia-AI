# Dawaya for Windows

Single-file Windows build of the Dawaya offline medicine guide.

- `main.go` — embedded-asset HTTP server (127.0.0.1 only) and window launcher: a native WebView2 window in-process, falling back to an Edge/Chrome app window if the WebView2 runtime is missing.
- `www/` — staged copy of `../dawaya-ios/webapp` (generated by the build script).
- `tools/` — application icon and a reference manifest.
- `build-windows.sh` — stages the web app, generates the resource object, and cross-compiles
  `dist/Dawaya.exe` (`GOOS=windows GOARCH=amd64`, GUI subsystem, no CGO).

Build (Go 1.23+):

```bash
go install github.com/tc-hib/go-winres@latest
./build-windows.sh
```

The resulting `dist/Dawaya.exe` is self-contained: it embeds every HTML/CSS/JS/JSON/font asset,
starts a loopback-only server on port 47123 (falls back to a free port), and opens the UI in a
Microsoft Edge app window with a dedicated profile under `%LOCALAPPDATA%\Dawaya\window`.

Run server-only (used for testing on macOS/Linux):

```bash
go build -o /tmp/dawaya-test .
/tmp/dawaya-test --no-browser --port 47123
```
