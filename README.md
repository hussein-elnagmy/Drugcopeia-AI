# Drugcopeia AI

A chat-first, on-device medicine information assistant. One conversation screen (ChatGPT/Claude style), Arabic and English, answers grounded in bundled sources with the safety rules of Drugcopeia. For education only; not a substitute for a doctor or pharmacist.

Web version: https://hussein-elnagmy.github.io/Drugcopeia-AI/

This is a separate program from Drugcopeia (https://github.com/hussein-elnagmy/Drugcopeia). Source is in `Source/`; the chat shell is `Source/webapp/ai-shell.*`.
